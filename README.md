# just-clock

Часы в терминале. Показывают местное время крупными символами и обновляются раз в секунду. Да, это буквально всё — и в этом идея.

## Запуск

Нужны Python 3. Работает только на терминале с командой `clear`. Сторонние Python-пакеты не требуются.

```bash
./clock.py
```

Или:

```bash
python3 clock.py
```

Для выхода используется `Ctrl+C` 

## Как это работает

`clock.py` получает текущее время в формате `ЧЧ:ММ:СС` через `time.strftime()`. Для каждой цифры и двоеточия в словаре `font` хранится рисунок из пяти строк. Программа печатает эти строки, ждёт одну секунду, очищает терминал и рисует время снова.

Время берётся из настроек системы. Сам скрипт не обращается к сети и не устанавливает пакеты
